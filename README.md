# حساب‌کتاب پوکر

سایت ثبت Buy-in و Cash-out برای شب‌های پوکر. امکاناتش:

- ورود با ایمیل و رمز
- روم‌های جدا، که فقط ادمین هر روم می‌تونه توشون ثبت کنه و بقیه زنده می‌بینن
- تسویه‌ی خودکار، با امکان خانواده
- تاریخچه‌ی بازی‌ها
- نمودار عملکرد
- خروجی اکسل
- حالت روشن و تاریک
- فارسی و انگلیسی

صفحه‌ها روی **GitHub Pages** و داده‌ها و ورود روی **Supabase** هستن. هر دو رایگانن و هاست جدا لازم نیست.

## فایل‌ها

| فایل | کارش |
|---|---|
| `index.html` | ظاهر سایت |
| `app.js` | منطق سایت |
| `config.js` | آدرس و کلید Supabase تو. **فقط این فایل رو باید عوض کنی.** |
| `supabase-schema.sql` | ساخت جدول‌ها و قوانین دسترسی در Supabase. یک بار اجرا می‌شه. |

---

## مرحله‌ی ۱: ساخت پروژه در Supabase

1. برو به [supabase.com](https://supabase.com) و با حساب GitHub یا ایمیل ثبت‌نام کن.
   > ممکنه Supabase از داخل ایران بدون فیلترشکن باز نشه. اگه باز نشد، برای ساختن پروژه از فیلترشکن استفاده کن. بعد از ساختن، چک کن دوستات بدون فیلترشکن به سایت وصل می‌شن یا نه.
2. **New project** رو بزن، یه اسم بده (مثلاً `poker`) و یه رمز برای دیتابیس بنویس و جایی نگه دار. Region رو نزدیک‌ترین جا انتخاب کن (مثلاً Frankfurt).
3. چند دقیقه صبر کن تا پروژه آماده بشه.

## مرحله‌ی ۲: ساخت جدول‌ها

1. از منوی کنار، **SQL Editor** رو باز کن و **New query** رو بزن.
2. کل محتوای فایل `supabase-schema.sql` رو کپی کن، اونجا Paste کن و **Run** رو بزن.
3. باید پیغام **Success** ببینی.

این اسکریپت کارهای زیر رو انجام می‌ده:
- جدول روم‌ها و بازی‌ها رو می‌سازه.
- قانون می‌ذاره که فقط سازنده‌ی هر روم بتونه توش بنویسه.
- آپدیت زنده رو روشن می‌کنه.

## مرحله‌ی ۳: تنظیم ورود

1. برو به **Authentication** و بعد تنظیمات Email (اسمش ممکنه **Sign In / Providers** یا **Providers → Email** باشه).
2. پیشنهاد: گزینه‌ی **Confirm email** رو خاموش کن. وگرنه هر کس ثبت‌نام می‌کنه باید اول ایمیلش رو تأیید کنه، و ایمیل‌های رایگان Supabase تعدادشون در ساعت محدوده.
3. بعد از مرحله‌ی ۵، توی **Authentication → URL Configuration**، آدرس سایتت رو به‌عنوان **Site URL** وارد کن. اینطوری لینک‌های ایمیل به سایت خودت برمی‌گردن.

## مرحله‌ی ۴: وارد کردن کلیدها در config.js

1. برو به **Project Settings → API** (یا **Data API** و **API Keys**).
2. **Project URL** رو کپی کن.
3. کلید **anon** یا **publishable** رو کپی کن.
   > کلید **service_role** یا **secret** رو **هیچ‌وقت** توی سایت نذار.
4. فایل `config.js` رو باز کن و این دو تا رو جایگزین کن:

```js
window.POKER_CONFIG = {
  url: "https://abcdefgh.supabase.co",
  key: "eyJhbGciOi..."
};
```

گذاشتن کلید anon توی سایت عمومی امنه. قوانین دیتابیس (Row Level Security) جلوی هر تغییر غیرمجاز رو می‌گیرن.

## مرحله‌ی ۵: گذاشتن سایت روی GitHub

1. وارد [github.com](https://github.com) شو، **New repository** رو بزن، یه اسم بده (مثلاً `poker`) و **Public** انتخاب کن.
2. توی صفحه‌ی ریپو، **Add file → Upload files** رو بزن. هر چهار فایل (`index.html`، `app.js`، `config.js`، `supabase-schema.sql`) رو بکش و بنداز و **Commit changes** رو بزن.
3. برو به **Settings → Pages**:
   - **Source**: Deploy from a branch
   - **Branch**: `main` و پوشه‌ی `/ (root)`
   - **Save** رو بزن.
4. بعد از یکی‌دو دقیقه آدرس سایتت بالای همون صفحه نشون داده می‌شه، چیزی مثل:
   `https://USERNAME.github.io/poker/`

## مرحله‌ی ۶: امتحان

1. سایت رو باز کن، **ثبت‌نام** کن و یه روم بساز. تو ادمین اون رومی.
2. لینک سایت رو برای دوستات بفرست. هر کس ثبت‌نام کنه همه‌ی روم‌ها رو می‌بینه. فقط ادمین هر روم می‌تونه Buy-in و Cash-out ثبت کنه.
3. هر کدوم از دوستات هم می‌تونه روم خودش رو بسازه و ادمین اون بشه.

## نکته‌ها

- **خاموش شدن پروژه‌ی رایگان:** Supabase پروژه‌های رایگانی رو که مدتی (حدود یک هفته) استفاده نشن موقتاً متوقف می‌کنه. اگه سایت وصل نشد، وارد داشبورد Supabase شو و **Restore** رو بزن. داده‌ها پاک نمی‌شن.
- **تغییر کد:** هر فایلی رو توی GitHub عوض کنی، بعد از یکی‌دو دقیقه روی سایت اعمال می‌شه.
- **داده‌های نسخه‌ی Claude** به این سایت منتقل نمی‌شن، چون دو تا دیتابیس جدان.
- **پشتیبان‌گیری:** توی Supabase از **Table Editor** می‌تونی جدول‌های `rooms` و `games` رو به‌صورت CSV دانلود کنی.
